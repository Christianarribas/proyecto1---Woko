# proyecto1---Woko

Proyecto realizado en clase: maqueta estática de una página de Woko, basada en una web hecha con WordPress. Esta versión está construida con HTML y CSS; no es un tema ni una instalación de WordPress.

## Qué incluye

- `index.html`: página principal con encabezado, menú, presentación, logos de clientes, bloques de servicios, tarjetas de proyectos y pie de página.
- `css/styles.css`: estilos, colores, tipografía y distribución de los elementos.
- `img/`: logo, imágenes y recursos utilizados en la página.

El diseño alterna secciones oscuras y claras con detalles verdes. Los botones y enlaces con `href="#"` son marcadores: todavía no llevan a otras páginas ni permiten reservar reuniones.

## Tecnologías

- HTML
- CSS con variables y Flexbox
- Tipografía Inter cargada desde Google Fonts

No utiliza JavaScript, librerías ni herramientas de compilación.

## Cómo verlo

1. Descarga el repositorio y descomprime el ZIP.
2. Abre `index.html` en el navegador (doble clic).
3. Conserva las carpetas `css/` e `img/` junto a `index.html` para que carguen los estilos y las imágenes.

No hace falta instalar dependencias. La tipografía de Google Fonts necesita conexión a internet.

## Qué aprendí

Aprendí a estructurar una página con encabezado, secciones y pie de página usando HTML. Practiqué la distribución de elementos con Flexbox y el uso de variables CSS para los colores. También practiqué cómo organizar los estilos y las imágenes en carpetas separadas.

## Pendiente

- Adaptar la distribución y el tamaño del texto a pantallas pequeñas: el CSS actual no incluye reglas `@media`.
- Cambiar los enlaces de ejemplo por destinos reales.
- Sustituir el texto provisional del encabezado principal.
- Corregir la variable `--colorle1` usada en los títulos `h4`, que no está definida en el CSS.

Es una práctica de maquetación, no una web oficial ni un servicio funcional de Woko.
